# 만주연방 — 7개 구성국 영토도

국호는 **한자 지명 + 공화국 / 자유국** 두 형태로만 통일했다. 민족의 개성은 정체(政體) 이름이 아니라 한자 지명에서 드러난다.

- **공화국**: 한 민족이 중심이고 정체성이 뚜렷한 나라
- **자유국**: 여러 민족이 함께하거나 연합·도시·완충 성격이 강한 나라

## 연방 직할지 (금색)

신징 연방직할시(수도), 대련 연방직할시, 만주리 연방직할구, 훈춘 연방직할구, (선택) 흥안령 연방직할구.
각 직할지는 해당 구성국 영토에서 떼어 낸 구역이라 겹치지 않는다. 대련은 봉천 공화국 남쪽에 붙어 있다.

## 지도에 가져오기 (Google My Maps)

1. [My Maps](https://www.google.com/mymaps) → **새 지도 만들기**
2. **가져오기** → `manchu-federation.kml` 업로드
3. 폴더 3개(구성국 영토 / 연방 직할지 / 중심 도시)가 나타난다. 각 영토를 누르면 국호·한자·주체·설명이 뜬다.

## 국경 구성 (실제 시·현 경계 기준)

| 국가 | 구성 |
|---|---|
| 만주 | 지린·쓰핑·랴오위안·퉁화·바이산·쑹위안·바이청 (신징=창춘은 직할시로 분리) |
| 봉천 | 선양·안산·푸순·번시·단둥·진저우·잉커우·랴오양·판진·톄링·후루다오 (다롄은 직할시로 분리) |
| 간도 | 옌볜 조선족 자치주 (훈춘은 직할구로 분리) |
| 흥안 | 후룬베이르·싱안맹·퉁랴오 (만주리·건허는 직할구로 분리) |
| 삼강 | 하얼빈을 뺀 헤이룽장 전역 (치치하르·다칭·자무쓰·무단장·헤이허·다싱안링 등) |
| 하얼빈 | 하얼빈시 전체 |
| 열하 | 청더·차오양·푸신·츠펑 |

> 지형과 경계는 실제 행정구역을 바탕으로 했고, 나라 구성과 이름은 창작이다. 국호 표기는 약칭 "만주국", "봉천국", "삼강국"처럼 앞 글자만 써도 된다. 옛 만주국(1932~45)과 혼동되면 1번을 "길림 공화국"(吉林共和國)으로 바꿀 수 있다.
