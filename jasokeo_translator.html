자소크어 알파벳 (24자 기본)

자소크어는 라틴 알파벳 기반이며, 각 문자는 고정된 발음값을 가집니다. 대소문자 구별: 명사는 첫 글자를 대문자로 씁니다.

잔음 (殘音, Residual Sound)

자음을 두 번 겹쳐 쓰면 잔음을 나타냅니다.
잔음 = 자음을 발음하고, 소리를 끝내면서 약한 중설 중모음(schwa [ə])을 내는 것.
예: ss = /sə/, ll = /lə/, nn = /nə/

특수 정서법 규칙

X 규칙: x는 어두(단어 맨 앞)에 올 수 없음. /ʃ/ 음소로 시작하는 단어는 ex-로 시작하며, 이 때 e는 묵음.

Q 규칙: q는 항상 u와 함께 qu 형태로만 씀. qu는 단어 끝에 올 수 없으므로, /k/ 음소로 끝나는 단어(고유명사 제외)는 -que로 끝내며 e는 묵음.

예: /ʃi/ 로 시작하는 단어 → Exi... (어두 e 묵음)
/pak/ 으로 끝나는 단어 → ...paque (어말 e 묵음)

기본 어순

자소크어의 기본 어순은 SOV (주어-목적어-동사)이지만, 조사가 격을 표시하므로 자유어순이 허용됩니다.
어순에 따라 조사의 위치가 달라집니다: 동사 앞 단어는 뒤에 조사, 동사 뒤 단어는 앞에 조사.

부정 (Negation)

동사 앞에 부정 접두사 na-를 붙입니다.
예: naquovizaxùm = 만나지 않는다

명사 복수

명사에 접미사 -si를 붙여 복수를 나타냅니다.
예: Ziroque → Ziroque-si = 친구들

의문문

문장 끝에 e를 붙이면 의문문, a를 붙이면 감탄문이 됩니다.
예: quovizaxùm e? = 만나나요?
