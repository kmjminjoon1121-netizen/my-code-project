# 천하(天下) — 대현(大玄) 제국 세계관

천룡력 1247년. 실제 중국 지형 위에 얹은 가상의 무협 판타지 세계관.

## 핵심 설정
- **용맥(龍脈)**: 황하(등뼈)와 장강(혈맥)을 따라 흐르는 천하의 기운. 내공, 술법, 영약의 근원이다.
- **현재 위기**: 대현 황제 현종 이휘가 근원인 구곡천을 장악해 용맥을 독점하려 한다. 강물이 마르는 징조가 시작되었다.
- **분위기**: 무협 + 궁중 음모 + 동양 판타지

## 세력 구도
| 세력 | 성향 | 목표 |
|---|---|---|
| 대현 제국 (현경) | 지배 | 용맥 독점 |
| 청허관 / 청류당 | 균형·저항 | 용맥 수호, 황제 견제 |
| 적송사 | 중립을 가장 | 황실과 밀약 |
| 낭혼 칸국 | 침략 | 중원 진출 |
| 사해 연맹 / 해월항 | 상업 | 이익 극대화 |
| 운무곡 / 흑림 | 은둔·암살 | 외부 개입 거부 |

## 이야기 갈고리
1. 초대 황제릉이 도굴당했고, 도굴된 물건은 용맥 봉인 열쇠다.
2. 폐관 10년의 청성검문주 유하연이 돌연 종적을 감췄다.
3. 월시에서 황실이 금지한 비급이 거래되고 있다.
4. 삼협 귀문에서 죽은 자가 돌아와 황도를 향해 걷고 있다.
5. 초원의 칸과 해적왕이 비밀리에 동맹을 맺었다는 소문.

## 지도에 가져오기 (Google My Maps)
1. [My Maps](https://www.google.com/mymaps) 접속 → **새 지도 만들기**
2. 왼쪽 패널에서 **가져오기** 클릭
3. `daehyeon-world.kml` 업로드
4. 5개 폴더(도시 / 문파 / 외부 세력 / 신비 / 길과 강)가 각각 레이어처럼 표시됩니다. 마커 아이콘과 색은 My Maps에서 자유롭게 바꿀 수 있어요.
